# راهنمای استقرار سامانه سیمولیشن کمپ روی هاست سی‌پنل (cPanel)

این بسته نرم‌افزاری به گونه‌ای طراحی شده است که با **کمترین زحمت ممکن** روی هر هاست اشتراکی لینوکس با کنترل‌پنل **cPanel** یا دایرکت‌ادمین (PHP 7.4 تا 8.3) اجرا شود.

---

## 🚀 روش نصب فوق‌سریع (بدون نیاز به ساخت دیتابیس - حالت SQLite خودکار)

1. وارد کنترل‌پنل **cPanel** خود شوید و به **File Manager** بروید.
2. وارد پوشه `public_html` (یا هر ساب‌دایرکتوری دلخواه مانند `public_html/camp`) شوید.
3. فایل فشرده `cpanel_export.zip` را در این پوشه **Upload** کرده و روی آن راست‌کلیک کرده و **Extract** کنید.
4. آدرس `https://domain.com/setup_db.php` را باز کنید و **رمز عبور سوپرادمین** را تعیین کنید (حداقل ۸ کاراکتر). این کار فقط یک‌بار انجام می‌شود و رمز به صورت هش ذخیره می‌شود.
5. **تمام شد!** سامانه با دیتابیس محلی SQLite کار می‌کند و نیازی به تنظیمات phpMyAdmin نیست.

> 🔐 رمز پیش‌فرض قدیمی `admin123` دیگر پذیرفته نمی‌شود. اگر ترجیح می‌دهید، می‌توانید رمز را مستقیماً در متغیر `$superadmin_pass` فایل `db.php` بنویسید.

---

## 🗄️ روش اتصال به دیتابیس MySQL سی‌پنل (اختیاری)

در صورتی که ترجیح می‌دهید از دیتابیس MySQL هاست استفاده کنید:
1. در سی‌پنل از بخش **MySQL Databases** یک دیتابیس و کاربر ساخته و دسترسی کامل (All Privileges) بدهید.
2. فایل `db.php` را در File Manager سی‌پنل باز کرده (Edit) و ۳ متغیر زیر را تکمیل کنید:
   ```php
   $servername = "localhost";
   $username   = "user_db";     // نام کاربری دیتابیس
   $password   = "pass_db";     // رمز عبور دیتابیس
   $dbname     = "name_db";     // نام دیتابیس
   ```
3. فایل را ذخیره کنید. جداول به صورت خودکار ساخته و ارتقاء داده می‌شوند.
4. (اختیاری) می‌توانید آدرس `https://domain.com/setup_db.php` را در مرورگر باز کنید تا وضعیت اتصال و جداول را بررسی کنید.

## 🎨 نحوه تغییر فاوآیکون (Favicon - آیکون تب مرورگر) در سی‌پنل

در این نسخه، دو فایل آیکون پیش‌فرض در پوشه اصلی قرار دارند:
- `favicon.png` (تصویر آیکون با فرمت PNG)
- `favicon.svg` (آیکون برداری با فرمت SVG با وضوح بالا)

### روش تغییر:
1. تصویر لوگو یا آیکون دلخواه خود را آماده کنید (پیشنهاد: ابعاد 32x32 یا 64x64 با فرمت PNG).
2. نام فایل را به `favicon.png` تغییر دهید.
3. در **File Manager** سی‌پنل وارد پوشه‌ای شوید که اسکریپت‌ها را در آن قرار داده‌اید (مثلاً `public_html/simcamp`).
4. دکمه **Upload** را در بالای File Manager بزنید و فایل جدید `favicon.png` را آپلود کنید. تیک گزینه **Overwrite existing files** را بزنید تا جایگزین فایل قبلی شود.
5. (اختیاری) اگر فایل با پسوند `.ico` یا `.svg` دارید نیز می‌توانید آن را با نام `favicon.ico` یا `favicon.svg` آپلود کنید.
6. **نکته مهم کش مرورگر:** مرورگرها آیکون تب (Favicon) را به شدت کَش می‌کنند. پس از جایگزینی، با فشردن کلیدهای `Ctrl + F5` (یا باز کردن صفحه در پنجره ناشناس / Incognito) تغییر آن را مشاهده فرمایید.

## 💾 پشتیبان‌گیری، سطل زباله و عکس‌ها

- **سطل زباله:** مسابقه‌ی حذف‌شده تا ۳۰ روز در «سطل زباله»ی پنل سوپرادمین می‌ماند و قابل بازگرداندن است؛ بعد از آن خودکار پاک می‌شود.
- **فایل پشتیبان:** از پنل سوپرادمین («خروجی» هر مسابقه یا «پشتیبان‌گیری ← دانلود پشتیبان کامل») و بازیابی با «بازیابی از فایل پشتیبان».
  فایل‌ها با نسخه Node هم سازگارند. برای بازیابی فایل‌های بزرگ ممکن است لازم باشد `post_max_size` و `upload_max_filesize` را در
  **MultiPHP INI Editor** سی‌پنل بیشتر کنید (مثلاً 100M).
- **پشتیبان خودکار روزانه:** در cPanel ← **Cron Jobs** یک کار روزانه بسازید:

  ```
  php /home/USERNAME/public_html/backup.php /home/USERNAME/simcamp-backups 14
  ```

  هر بار یک فایل کامل (همه مسابقه‌ها، امتیازها و عکس‌ها) ساخته می‌شود و فقط ۱۴ فایل آخر نگه داشته می‌شود. بهتر است پوشه‌ی مقصد بیرون از
  `public_html` باشد. اگر پوشه‌ای ندهید، فایل‌ها در `data/backups` (غیرقابل دسترس از وب) ذخیره می‌شوند. `backup.php` از مرورگر اجرا نمی‌شود.
  با MySQL، پشتیبان‌گیری خود سی‌پنل (Backup / JetBackup) را هم فعال نگه دارید.
- **عکس‌ها:** عکس تیم‌ها و لوگوها به صورت فایل در `data/media` ذخیره و با `media.php` (با کش یک‌ساله مرورگر) نمایش داده می‌شوند.
  عکس‌های مسابقه‌های قدیمی در اولین استفاده خودکار به فایل تبدیل می‌شوند. هنگام انتقال هاست، پوشه‌ی `data` را هم منتقل کنید.
- **پاسخ «بدون تغییر»:** اگر داده‌ی مسابقه عوض نشده باشد، سرور به تابلو و پنل‌ها پاسخ کوتاه `304` می‌دهد و پهنای باند و پردازش کمتری مصرف می‌شود.

## 🛠️ برای توسعه‌دهندگان

فایل‌های HTML/CSS/JS این پوشه به صورت خودکار از پوشه `public/` ساخته می‌شوند. تغییرات را فقط در `public/` انجام دهید و سپس دستور زیر را اجرا کنید:

```bash
npm run build:cpanel
```

فایل‌های `api.php`، `db.php`، `setup_db.php`، `media.php`، `backup.php`، `index.php` و `.htaccess` مخصوص همین نسخه هستند و توسط build بازنویسی نمی‌شوند.
