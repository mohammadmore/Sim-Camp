# چک‌لیست نصب سیم‌کمپ روی `studio.asvashop.com/simcamp`

این راهنما برای کسی نوشته شده که تجربه‌ی قبلی ندارد. مراحل را **به ترتیب** انجام دهید و جلوی هر مرحله که تمام شد تیک بزنید.
زمان لازم: حدود ۳۰ دقیقه.

نسخه‌ی نصب: نسخه‌ی سی‌پنل (PHP) با دیتابیس SQLite. دیتابیس جداگانه (MySQL) لازم نیست.

---

## پیش از شروع، این‌ها را آماده کنید

- [ ] **نام کاربری و رمز کنترل‌پنل (cPanel) هاست.** آدرس ورود معمولاً یکی از این‌هاست:
  `https://asvashop.com:2083` یا `https://asvashop.com/cpanel` (اگر نمی‌دانید، از شرکت هاستینگ بپرسید).
- [ ] **فایل `cpanel_export.zip`** (بسته‌ی آماده‌ی نصب). این فایل را جدا دریافت کرده‌اید؛ آن را **باز نکنید** و همان‌طور نگه دارید.
- [ ] **یک رمز قوی برای سوپرادمین** (حداقل ۸ کاراکتر، ترکیب حروف انگلیسی و عدد). آن را جایی امن یادداشت کنید.
  این رمز، کلید کل سیستم است.
- [ ] یک کامپیوتر (برای نصب) و یک گوشی (برای تست آخر).

---

## مرحله ۱: ورود به cPanel

- [ ] آدرس ورود cPanel را در مرورگر باز کنید، نام کاربری و رمز را وارد کنید و **Log in** را بزنید.
- [ ] اگر صفحه انگلیسی است مشکلی نیست؛ نام منوها در این راهنما به انگلیسی آمده است.
  برای پیدا کردن هر منو می‌توانید نامش را در کادر جستجوی بالای صفحه‌ی cPanel تایپ کنید.

## مرحله ۲: اطمینان از وجود زیردامنه‌ی `studio.asvashop.com`

- [ ] در cPanel منوی **Domains** را باز کنید (در بعضی هاست‌ها **Subdomains**).
- [ ] در فهرست، دنبال `studio.asvashop.com` بگردید.
  - **اگر هست:** جلوی آن ستون **Document Root** را ببینید و مسیرش را یادداشت کنید
    (مثلاً `/home/asvauser/studio.asvashop.com` یا `public_html/studio`). در ادامه به این مسیر «پوشه‌ی اصلی زیردامنه» می‌گوییم.
  - **اگر نیست:** دکمه‌ی **Create A New Domain** را بزنید، در کادر Domain بنویسید `studio.asvashop.com`،
    تیک **Share document root** را (اگر هست) بردارید و **Submit** بزنید. سپس مسیر Document Root ساخته‌شده را یادداشت کنید.
- [ ] **فقط اگر DNS دامنه جای دیگری است** (مثلاً Cloudflare): در پنل DNS آنجا یک رکورد **A** با نام `studio`
  بسازید که به IP هاست اشاره کند (IP در ستون کناری صفحه‌ی اصلی cPanel با عنوان **Shared IP Address** آمده است).
  اگر نمی‌دانید DNS کجاست، از شرکت هاستینگ بپرسید. ممکن است تا چند ساعت طول بکشد تا زیردامنه کار کند.

## مرحله ۳: فعال کردن گواهی امنیتی (HTTPS)

بدون HTTPS، حالت آفلاین و نصب برنامه روی گوشی کار نمی‌کند.

- [ ] منوی **SSL/TLS Status** را باز کنید.
- [ ] جلوی `studio.asvashop.com` باید قفل سبز و عبارت **AutoSSL Domain Validated** باشد.
- [ ] اگر نیست: تیک کنار آن را بزنید و دکمه‌ی **Run AutoSSL** را بزنید. چند دقیقه صبر کنید و صفحه را دوباره باز کنید تا سبز شود.
- [ ] در مرورگر `https://studio.asvashop.com` را باز کنید. نباید هشدار «Not secure» یا «اتصال امن نیست» بدهد.

## مرحله ۴: تنظیم نسخه‌ی PHP

- [ ] منوی **MultiPHP Manager** را باز کنید.
- [ ] تیک کنار `studio.asvashop.com` را بزنید، از فهرست کشویی سمت راست **PHP 8.2** (یا 8.1) را انتخاب و **Apply** را بزنید.
  (نسخه‌های ۷.۴ تا ۸.۳ پشتیبانی می‌شوند؛ ۸.۴ تست نشده است.)
- [ ] **اگر منوی Select PHP Version وجود دارد** (در بعضی هاست‌ها): آن را باز کنید و در بخش Extensions مطمئن شوید این‌ها تیک دارند:
  `pdo_sqlite`، `sqlite3`، `mbstring`، `curl`. اگر این منو را ندارید، نگران نباشید؛ در مرحله‌ی ۹ معلوم می‌شود همه‌چیز آماده است.

## مرحله ۵: تنظیم حجم آپلود (برای عکس تیم‌ها و فایل پشتیبان)

- [ ] منوی **MultiPHP INI Editor** را باز کنید، از فهرست کشویی `studio.asvashop.com` را انتخاب کنید.
- [ ] این مقادیر را تنظیم کنید و پایین صفحه **Apply** را بزنید:

  | تنظیم | مقدار |
  |---|---|
  | `upload_max_filesize` | `64M` |
  | `post_max_size` | `64M` |
  | `memory_limit` | `256M` |
  | `max_execution_time` | `60` |

## مرحله ۶: ساخت پوشه‌ی `simcamp`

- [ ] منوی **File Manager** را باز کنید.
- [ ] بالای صفحه دکمه‌ی **Settings** را بزنید، تیک **Show Hidden Files (dotfiles)** را بزنید و **Save** کنید
  (بعداً لازم است فایل مخفی `.htaccess` را ببینید).
- [ ] در ستون چپ، به **پوشه‌ی اصلی زیردامنه** (مسیری که در مرحله‌ی ۲ یادداشت کردید) بروید و روی آن کلیک کنید.
- [ ] دکمه‌ی **+ Folder** را بزنید، نام را دقیقاً `simcamp` بنویسید (حروف کوچک، بدون فاصله) و **Create New Folder** را بزنید.

## مرحله ۷: آپلود بسته

- [ ] روی پوشه‌ی تازه‌ی `simcamp` **دوبار کلیک** کنید تا واردش شوید (مسیر بالای صفحه باید به `/simcamp` ختم شود).
- [ ] دکمه‌ی **Upload** را بزنید، فایل `cpanel_export.zip` را انتخاب کنید و صبر کنید نوار پیشرفت سبز و **100%** شود.
- [ ] لینک **Go Back to "…/simcamp"** را بزنید تا به پوشه برگردید.

## مرحله ۸: باز کردن (Extract) بسته

- [ ] روی فایل `cpanel_export.zip` **راست‌کلیک** کنید و **Extract** را بزنید.
- [ ] در پنجره‌ی باز شده، مسیر باید همان پوشه‌ی `simcamp` باشد (تغییرش ندهید). **Extract File(s)** و بعد **Close** را بزنید.
- [ ] دکمه‌ی **Reload** را بزنید. **باید مستقیماً داخل `simcamp` این فایل‌ها را ببینید:**
  `api.php`، `superadmin.html`، `operator.html`، `board.html`، `setup_db.php`، `.htaccess`، پوشه‌های `vendor` و `lang` و …
  - اگر به‌جای آن‌ها فقط یک پوشه به نام `cpanel_export` می‌بینید: واردش شوید، همه‌چیز را انتخاب کنید (**Select All**)،
    **Move** را بزنید، مسیر را به `…/simcamp` تغییر دهید و منتقل کنید. سپس پوشه‌ی خالی `cpanel_export` را پاک کنید.
  - اگر `.htaccess` را نمی‌بینید: تنظیم Show Hidden Files در مرحله‌ی ۶ را دوباره بررسی کنید.
- [ ] فایل `cpanel_export.zip` را انتخاب کنید و **Delete** کنید (دیگر لازم نیست).

## مرحله ۹: تعیین رمز سوپرادمین

- [ ] در مرورگر این آدرس را باز کنید: `https://studio.asvashop.com/simcamp/setup_db.php`
- [ ] صفحه باید وضعیت دیتابیس را **سبز** (SQLite آماده) نشان دهد.
- [ ] رمز سوپرادمین را (که از قبل آماده کرده‌اید) در هر دو کادر بنویسید و دکمه‌ی ثبت را بزنید.
- [ ] پیام «رمز سوپرادمین با موفقیت ثبت شد» را ببینید.
  این صفحه بعد از اولین ثبت، **قفل** می‌شود و دیگر کسی نمی‌تواند از آن رمز تعیین کند.
- [ ] اگر خطای دیتابیس دیدید: بخش «رفع اشکال» در انتهای همین فایل را ببینید.

## مرحله ۱۰: ورود به پنل سوپرادمین

- [ ] آدرس `https://studio.asvashop.com/simcamp/` را باز کنید؛ خودکار به پنل سوپرادمین می‌رود.
- [ ] رمز سوپرادمین را وارد کنید و وارد شوید. باید «داشبورد سوپرادمین» را ببینید.
- [ ] این آدرس را در بوکمارک مرورگر ذخیره کنید.

## مرحله ۱۱: آزمایش کامل (حدود ۱۰ دقیقه)

- [ ] **ساخت مسابقه‌ی آزمایشی:** «مسابقه جدید» را بزنید؛ نام سازمان، عنوان مسابقه و **رمز اپراتور** را بنویسید،
  دو تیم و یک مرحله اضافه کنید و «ذخیره» را بزنید.
- [ ] روی کارت مسابقه دکمه‌ی **«لینک‌ها و QR»** را بزنید. لینک‌های پنل اپراتور، تابلوی زنده و … اینجا هستند.
- [ ] **پنل اپراتور** را در یک تب جدید باز کنید. نام کاربری `admin` و همان رمز اپراتور را وارد کنید.
  برای یک تیم عدد ۵ را بنویسید و «ثبت» را بزنید.
- [ ] **تابلوی زنده** را در تب دیگری باز کنید؛ امتیاز ۵ باید روی تابلو دیده شود.
- [ ] **روی گوشی:** QR پنل اپراتور را با دوربین گوشی اسکن کنید، وارد شوید و یک امتیاز دیگر ثبت کنید. تابلو باید به‌روز شود.
- [ ] اگر آیفون دارید، همین آزمایش را با **Safari** آیفون هم انجام دهید.
- [ ] در پایان، روی کارت مسابقه‌ی آزمایشی «حذف» را بزنید (به سطل زباله می‌رود و بعد از ۳۰ روز خودکار پاک می‌شود).

## مرحله ۱۲: بررسی امنیت (۲ دقیقه)

- [ ] این آدرس را باز کنید: `https://studio.asvashop.com/simcamp/data/simul_camp.sqlite`
  باید خطای **403 Forbidden** (یا «دسترسی ممنوع») ببینید. **اگر فایلی دانلود شد، یعنی اطلاعات در خطر است**:
  مطمئن شوید فایل `.htaccess` در `simcamp` و `data` وجود دارد و موضوع را با شرکت هاستینگ در میان بگذارید.
- [ ] این آدرس هم باید **403** بدهد: `https://studio.asvashop.com/simcamp/README.md`
- [ ] دوباره `https://studio.asvashop.com/simcamp/setup_db.php` را باز کنید؛ نباید امکان تعیین رمز جدید بدهد.

## مرحله ۱۳: پشتیبان‌گیری خودکار روزانه

- [ ] منوی **Cron Jobs** را باز کنید.
- [ ] در بخش **Add New Cron Job**، از فهرست **Common Settings** گزینه‌ی **Once Per Day** را انتخاب کنید.
- [ ] در کادر **Command** این را بنویسید و `مسیر-زیردامنه` را با Document Root مرحله‌ی ۲ جایگزین کنید:

  ```
  /usr/local/bin/php مسیر-زیردامنه/simcamp/backup.php
  ```

  مثال: `/usr/local/bin/php /home/asvauser/studio.asvashop.com/simcamp/backup.php`
  (اگر Document Root به شکل `public_html/studio` بود، مسیر کامل می‌شود `/home/نام‌کاربری/public_html/studio/simcamp/backup.php`؛
  نام کاربری cPanel بالای صفحه‌ی File Manager در مسیر پوشه‌ی اصلی دیده می‌شود.)
- [ ] **Add New Cron Job** را بزنید.
- [ ] فردای آن روز در File Manager پوشه‌ی `simcamp/data/backups` را باز کنید؛ باید یک فایل پشتیبان ساخته شده باشد.
  (سیستم ۱۴ فایل آخر را نگه می‌دارد.)
- [ ] علاوه بر این، **قبل و بعد از هر مسابقه‌ی مهم**: در پنل سوپرادمین «پشتیبان‌گیری ← دانلود پشتیبان کامل» را بزنید
  و فایل را روی کامپیوتر خودتان نگه دارید.

## مرحله ۱۴ (اختیاری، پیشنهادی): هشدار قطعی

- [ ] در سایت رایگان **UptimeRobot** یک مانیتور از نوع **Keyword** بسازید با آدرس
  `https://studio.asvashop.com/simcamp/api.php?action=health` و کلمه‌ی `ok`، تا اگر سیستم از کار افتاد ایمیل هشدار بگیرید.

## مرحله ۱۵: قبل از روز مسابقه

- [ ] مسابقه‌ی واقعی را بسازید، کاربران (داورها) را در فرم مسابقه تعریف کنید و لینک/QR پنل اپراتور را برایشان بفرستید.
- [ ] از داورها بخواهید یک روز قبل لینک را روی گوشی باز کنند، وارد شوند و (اختیاری) **Add to Home Screen** بزنند.
- [ ] روز مسابقه، قبل از شروع، از همه بخواهید صفحه را یک بار **رفرش** کنند.
- [ ] تابلوی زنده را روی تلویزیون/پروژکتور باز کنید و دکمه‌ی تمام‌صفحه را بزنید.

## به‌روزرسانی در آینده (وقتی نسخه‌ی جدید رسید)

1. [ ] در پنل سوپرادمین «پشتیبان‌گیری ← دانلود پشتیبان کامل» را بزنید و فایل را نگه دارید.
2. [ ] در File Manager روی پوشه‌ی `simcamp/data` راست‌کلیک ← **Compress** ← Zip، و فایل zip ساخته‌شده را **Download** کنید.
3. [ ] وسط مسابقه‌ی در جریان به‌روزرسانی نکنید.
4. [ ] فایل `cpanel_export.zip` جدید را مثل مراحل ۷ و ۸ داخل `simcamp` آپلود و Extract کنید و اجازه دهید فایل‌های قبلی جایگزین شوند
   (پوشه‌ی `data` داخل بسته نیست، پس اطلاعات دست نمی‌خورد).
5. [ ] فقط اگر قبلاً در `db.php` اطلاعات MySQL وارد کرده بودید: قبل از Extract از `db.php` کپی بگیرید و بعد برگردانید.
   (در این نصب از SQLite استفاده شده و این مورد لازم نیست.)
6. [ ] پنل را باز کنید، یک بار رفرش کنید و مرحله‌ی ۱۱ را سریع تکرار کنید.

## رفع اشکال

| مشکل | علت و راه‌حل |
|---|---|
| آدرس `…/simcamp/` خطای **404** می‌دهد | پوشه‌ی `simcamp` در جای درست (Document Root زیردامنه، مرحله‌ی ۲) نیست، یا فایل‌ها داخل یک پوشه‌ی اضافه‌ی `cpanel_export` هستند (مرحله‌ی ۸). نام پوشه هم باید دقیقاً `simcamp` با حروف کوچک باشد. |
| خطای **500 Internal Server Error** | نسخه‌ی PHP را در مرحله‌ی ۴ بررسی کنید (۸.۱ یا ۸.۲). اگر حل نشد، متن خطا را از منوی **Errors** در cPanel کپی کنید و برای پشتیبانی بفرستید. |
| `setup_db.php` خطای دیتابیس/SQLite می‌دهد | افزونه‌ی `pdo_sqlite` روی هاست فعال نیست (مرحله‌ی ۴). از شرکت هاستینگ بخواهید آن را فعال کند. |
| پیام «پوشه data قابل نوشتن نیست» | در File Manager روی پوشه‌ی `simcamp` راست‌کلیک ← **Change Permissions** ← عدد `755` را وارد کنید. |
| مرورگر می‌گوید «اتصال امن نیست» | مرحله‌ی ۳ (SSL) کامل نشده است. |
| رمز سوپرادمین را قبول نمی‌کند | زبان صفحه‌کلید (فارسی/انگلیسی) و Caps Lock را بررسی کنید. اگر رمز فراموش شد، با پشتیبانی فنی تماس بگیرید (بازیابی نیاز به دسترسی به فایل‌ها دارد). |
| آپلود عکس تیم انجام نمی‌شود | مقادیر مرحله‌ی ۵ را بررسی کنید. |
| بعد از به‌روزرسانی، ظاهر قدیمی دیده می‌شود | صفحه را یک بار رفرش کنید (روی کامپیوتر Ctrl+F5). |
